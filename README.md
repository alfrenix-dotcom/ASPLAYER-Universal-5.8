# ASPLAYER Universal 5.8 — LibVLC

Proyecto experimental de ASPLAYER para Android móvil y Android TV. Usará LibVLC 3.7.7; no incluye ni copia el reproductor propietario de IPTV Smarters Pro.

El código y la compilación se preparan en este repositorio privado. No introducir credenciales de usuarios o tokens en el repositorio.
